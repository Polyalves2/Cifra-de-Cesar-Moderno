# Cifra-de-Cesar-Moderno
# Projeto criado para a disciplina de Segurança.   ## Como funciona a criptografia: ### **Consoante:** avança 3 letras no alfabeto  ### **Vogal:** volta 2 letras no alfabeto ### **Espaço:** substituído por número aleatório ### **Quando for vogal:** adiciona / junto  ## Comando para rodar no vs code:  ### python cifra.py
